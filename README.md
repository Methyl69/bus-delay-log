# Bus delay log

Log every bus you catch and see your average delay and the best times of day to travel. Add buses by route number and path (for example 138, Pettah to Homagama), then log trips against them.

Runs entirely in the browser. Data is saved in your browser's local storage. No install, no backend.

## Use it

Open `index.html` in a browser, or host it with GitHub Pages.

## Features

- Multiple buses, each with a route number and path
- Average delay, on-time rate (within 5 minutes) and trip count
- Average delay by hour of day
- Best time windows and times to avoid
- Filter by bus
